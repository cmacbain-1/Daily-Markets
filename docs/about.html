The Morning Ledger

About this project

The Morning Ledger is a daily markets newspaper that researches, writes and publishes itself every weekday at 7am New York time, before Wall Street opens. It was designed and built by Calum MacBain, a finance student.

How it works

  1. Collects the data. Each morning a program downloads the latest prices for 81 markets from Yahoo Finance and works out how far each one moved over the day, week, month and year.
  2. Draws the charts. The same program turns those numbers into the charts and tables in each edition.
  3. Writes the story. Claude, an AI model made by Anthropic, reads the numbers, searches the news to find out why markets moved, and writes the article. It is instructed to quote only the real data and to list its sources.
  4. Publishes the paper. Everything is assembled into a web page and published, with every past edition kept in the archive.

The whole process runs automatically in the cloud on GitHub Actions, with no one needing to press a button.

A note on accuracy

Prices come from Yahoo Finance and may be delayed. The articles are written by AI, which is told to quote only the real data, but they can still contain mistakes. Nothing here is investment advice.
